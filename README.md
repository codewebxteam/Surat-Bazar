# Surat-Bazar

A premium luxury Indian saree & ethnic wear e-commerce web platform built with Next.js, Tailwind CSS, and Framer Motion.

## Features
- **Curated Collections**: Kanjivaram, Banarasi, Chanderi, Georgette, Organza, Bridal, and Occasion wear.
- **Interactive Shopping**: Dynamic filters, sorting, search, quick view, and responsive product catalog.
- **Cart & Wishlist**: Real-time state management with cart slide-over, coupon application, and persistent storage.
- **Checkout & Account**: Multi-step checkout, order confirmation, user dashboard, and tracking.
- **Luxury UI/UX**: Royal Indian color palette, gold accents, smooth animations, and mobile-responsive design.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
